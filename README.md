[chfem](https://github.com/cortezpedro/chfem) -- Computational Homogenization with the image-based Finite Element Method, a software written in C and CUDA, wrapped in Python, for the computational homogenization of material samples characterized via $\mu$-CT.

[pytomoviewer](https://github.com/LCC-UFF/pytomoviewer) -- Python script for the visualization of micro-computed tomographic images, from TIFF files, and a converter from TIFF to binary RAW files.
